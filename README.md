# ViralCutter (Русская версия)

Локальный open-source инструмент для нарезки длинных видео в вертикальные клипы (Shorts/Reels/TikTok) с авто-субтитрами, AI-анализом и красивыми RGB-стилями.

## Что улучшено в этой версии

- Интерфейс и сообщения по умолчанию запускаются на русском (`ru_RU`).
- Улучшена стабильность генерации субтитров:
  - нормализация режимов отображения (`word_by_word`, `no_highlight`) для совместимости со старыми проектами;
  - защита от проблемных таймингов (слишком короткие/ломаные интервалы);
  - более устойчивый рендер превью-субтитров.
- Улучшен RGB стиль субтитров:
  - добавлен пресет **RGB Neon Pro**;
  - улучшено неоновое свечение в HTML-превью.
- Упрощён запуск на Windows 11:
  - `INSTALL.bat` — установка;
  - `START_WINDOWS_11.bat` — запуск WebUI.
- Удалены лишние устаревшие `.bat`-скрипты.

## Быстрый запуск (Windows 11)

1. Установите Python 3.10–3.12 и FFmpeg.
2. Запустите `INSTALL.bat`.
3. Запустите `START_WINDOWS_11.bat`.
4. Откройте в браузере: `http://127.0.0.1:7860`

## Примечания

- Для максимальной скорости рекомендуется NVIDIA GPU.
- Если хотите принудительно сменить язык, используйте переменную окружения:
  - `VIRALCUTTER_LANG=ru_RU` (русский)
  - `VIRALCUTTER_LANG=en_US` (английский)
  - `VIRALCUTTER_LANG=pt_BR` (португальский)
